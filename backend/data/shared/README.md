# 共享资源目录

此目录用于存放可跨预设包使用的通用资源。

## 目录结构

```
shared/
├── characters/      # 通用角色卡（如：全知叙述者、旁白）
├── personas/        # 通用玩家人设（如：观察者、旁观者）
├── scenarios/       # 通用场景（如：神秘房间、十字路口）
└── prompts/         # 通用 Prompt 预设（如：基础叙事模板）
```

## 使用说明

- 放在 `shared/` 目录下的资源会被所有预设包共享
- 适合放置一些通用的、不特定于某个世界观的资源
- 这些资源的 `pack_id` 字段为空，在前端显示时不会被筛选

## 注意

**世界书不应该放在 shared 目录下！**

世界书应该：
- 要么作为预设包的一部分：`preset_packs/{pack_name}/worldbooks/`
- 要么不创建（每个预设包必须有自己的世界书）

独立的世界书没有意义，因为：
1. 世界书定义了世界观的核心设定
2. 应该与角色卡、人设等配套资源打包在一起
3. 选择世界书就是选择预设包
