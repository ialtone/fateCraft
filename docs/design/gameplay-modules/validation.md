- 规则不可用、目录数量限制、未知名称、未启用动作及过期预览分别处理；只读限制不变成可执行工具。

执行 `go test ./... -count=1`、`go vet ./...` 及 `git diff --check` 完成本地复核。未配置 `FATECRAFT_TEST_DATABASE_URL`，PostgreSQL 用例跳过；没有调用真实付费模型，也没有访问或修改玩家对话。本次纯后端与文档改动，未重新运行前端构建。

真实环境仍由维护者验证：未圆满闭关后正文不宣称突破，拒绝后不编造结果，普通状态问答依据当前面板；继续叙事、改写、终局收尾、幂等回放和事务故障下反馈与存档一致。可控响应验证平台装配和流程，不能用来宣称真实模型错误率已降低到某个数值或自由叙事永远正确。

## 维护者操作清单

1. 用空测试 schema 显式执行迁移，确认空库默认导入九个包；已有内容库仅补齐缺失包，停用状态、管理员修改和已有版本保持不变。测试停用后列表/详情/新开局受阻、已有存档可继续，以及重新启用和发布/覆盖后仍保持停用。
2. 在后台逐个导入新示例，修改规则、切换出身、保存、发布、导出并再次校验。故意移除必要行动或填入无效引用，确认发布拒绝且草稿仍可编辑。
3. 每种玩法走通一次成功及失败/放弃，覆盖服务器路由与客户端直连；七个示例默认 0 分。非零金额仅在隔离测试配置下验账。
4. 测试双击/超时后同请求重试、旧 revision、切换对话后迟到响应、刷新、断线、生成时操作与生成失败后的继续叙事。
5. 对已提交行动改写/重新生成，核对物资、任务、敌人、生产队列、随机历史有效分支、账号余额和账本，不得重复领奖。
6. 检查桌面和手机状态/行动页、动态方案、长列表、成本、错误与加载状态；问答不能泄露种子、未来随机或未公开事实。
7. 使用真实模型完成每种最小流程，记录请求次数、时间、token、可理解性和规则拒绝原因；本地规则测试不能代替这一项。
